# /forge-orchestrator

You are entering the forge orchestrator **in-pane** in the current session —
the no-argument manual entry point. `/forge` runs the same in-pane orchestrator
but adds the argument grammar (pipeline / fix-pipeline / resume / status /
pause) and seeds the run; use this command for debugging, manual stage runs, or
one-off pipeline operations where you want to drive the orchestrator directly
without that grammar.
